# Лекции. Требования:
- Посещаемость - осуществляется контроль посещаемости;
- Написание конспекта лекций - студент готовит рукописный конспект лекций

# Контроль экзамен
- **Экзамен** - комбинированный: письменная часть + устная
К устной допускается те, кто успешно сдал письменную часть экзамена. Оценка ставится по результату устного экзамена.

**Практикум** (зачёт с оценкой). Учтывается:
- работа в классе;
- оценки по контрольным работам (2 курсовые контрольные работа в системе Ejudge);
- выполнение практических заданий.
**Неуспевающие** (те, кто не получит незачёт) идут на комиссию.
**Комиссия** - контрольная работа в системе **Ejudge**.

# Коллоквиум
**Письменный Коллоквиум** (проходит *6 декабря*) - задачи на программирование по тематике курса: *теоретические вопросы*.

<u>Поощрение сдавших успешно коллоквиум:</u>
**Если**:
	- Студент не имеет проблем с посещаемостью лекций;
	- Подготовил качественный рукописный конспекты лекций;
	- Получил отличную или хорошую оценку на зачёте по практикуму;
	- Успешно сдал коллоквиум
**То**:
	Студенту предлагается оценка-автомат за курс Операционные системы

*Во время проведения коллоквиума, экзамена, курсоввых контрольных работ и комиссий по практикуму запрещается иметь с собой в аудитории любые электронные устройства. В случае выявления фактаналичия электронного устройства выставляется неудовлетворительная оценка*

	0.2. Основы архитектуры вычислительной системы

	3. Взаимодействие процессов

4. **Управление внешними устройствами**
	1. Общие концепции

5. **Управление оперативной памятью**
	1. Модели организации оперативной памяти. Основные алгоритмы и понятия

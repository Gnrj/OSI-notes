# Одиночное непрерывное распределение
![](_resources/Pasted%20image%2020251106115035.png)
- Расмещён один процесс

## Необходимые аппаратные средства
- Регистр границы 
- Режим ОС и пользовательский режим

- **Алгоритмы**: из практически нет
- **Достоинства**: простота
## Недостатки
1. Часть памяти не используется
2. Процессом/заданием память занимается все время выполнения
3. Ограничение на размеры задания

Свободная память идёт на файловую систему
# Распределение неперемещаемыми разделами
![](_resources/Pasted%20image%2020251106115614.png)

2 модели использования:
	1. Весь поток задач разделяем на n очередей, где n - количество разделов
	2. Рассматриваем не n очередей, а одну очередь на все разделы
## Необходимо
- Регистры границ
- Режим ОС
